Ouvrir `simulateur.html` dans un navigateur moderne pour utiliser le compagnon hors ligne.

Exécuter le test d'interface : `python test_interface_glissade_v090.py` (Playwright et Chromium requis).

Voir `RAPPORT_V090.md` pour les contrôles et limites.
