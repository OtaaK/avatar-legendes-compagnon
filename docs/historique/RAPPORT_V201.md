# V2.01 — Étoile de lave : Fracasser gratuit

- Nouvelle commande MJ **Fracasser le décor (gratuit)** sur une étoile active.
- Associe explicitement la destruction à une attaque déjà résolue pendant la passe du porteur.
- Demande confirmation MJ et description du décor, limite à une destruction par attaque.
- Journalise l’effet sans fatigue supplémentaire, conserve l’historique et permet Annuler.
- Refuse étoile éteinte, attaque absente, proposition en attente, double utilisation et description vide.
- Limite : le MJ confirme que l’attaque a réellement utilisé l’étoile ; ce lien n’est pas déductible automatiquement.
