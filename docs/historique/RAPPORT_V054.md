# V0.54 — Se mettre à l’abri

Source : technique universelle **Se mettre à l’abri**, page 286 du PDF officiel.

- La première attaque hostile réussie contre le personnage pendant la passe est absorbée par l’abri.
- Les effets simultanés rattachés à la même action (`actionId`) sont tous absorbés.
- La garde est consommée seulement après validation ; prévisualisation, refus et annulation sont sans effet durable.
- La seconde attaque réussie de la passe s’applique normalement.
- L’abri est noté comme endommagé ou détruit ; son état matériel précis reste une décision narrative du MJ.
- Limites : la réussite et la portée de l’attaque sont déterminées par le MJ ; les effets d’une même attaque doivent partager l’identifiant d’action. Aucun test navigateur réel effectué.

**8 / 102** techniques avancées disposent de tests dédiés.
