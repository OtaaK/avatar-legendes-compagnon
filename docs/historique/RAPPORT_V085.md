# Rapport V0.85 — Nouvelle technique technologique

## Modification
- **Meilleur, plus rapide, plus fort** (p. 293) : 1 fatigue pour un changement de position sans opposition, confirmé par le MJ.
- Option supplémentaire pour 1 fatigue : statut Renforcé tant que la position est tenue, ou sécurisation narrative d'une zone dangereuse.
- Description explicite de la position ; aucune distance, coordonnée ou durée inventée.
- Prévisualisation, décisions individuelles du MJ et annulation via le moteur existant.

## Contrôles
- 55 fichiers de tests Node.js réussis, dont 8 scénarios nouveaux.
- Syntaxe du JavaScript intégré : valide.
- Test navigateur complet : non exécuté / non confirmé.

## Limites
- Le statut Renforcé doit être retiré par le MJ lorsque la position n'est plus tenue.
- La zone sécurisée est un effet narratif suivi par le MJ, sans automatisation de ses interactions futures.
- Le compteur de techniques entièrement automatisées n'est pas augmenté : automatisation assistée partielle, à auditer.
