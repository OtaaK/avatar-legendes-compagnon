# V2.10 — Provenance des statuts temporaires

Un statut temporaire (notamment Gêné des Mouvements tectoniques) peut désormais recevoir une source indépendante ultérieure sans être effacé en fin de passe. Les applications explicites de statut marquent la provenance indépendante même lorsque le statut est déjà visible. L’expiration retire correctement les statuts sans source et nettoie leur repère de passe. Annulation et compatibilité testées.

Limites : autres interactions complexes entre sources à vérifier lors de combats complets.
