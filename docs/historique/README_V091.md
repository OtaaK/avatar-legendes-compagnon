# Avatar Légendes : Compagnon V0.91

Ouvrir `simulateur.html` dans un navigateur. La technique **Pose de pièges** est disponible dans l'approche Esquiver et analyser pour les combattants autorisés. Décrire la zone, proposer la technique et confirmer les effets. Dans la liste des combattants, le bloc **Pièges armés (MJ)** permet de déclencher le piège lorsque le prochain adversaire pénètre dans la zone.

Le MJ confirme la cible, l'état à cocher et la direction du décentrage. Le bouton d'annulation restaure les pièges et les statistiques. Détails dans `RAPPORT_V091.md`.
