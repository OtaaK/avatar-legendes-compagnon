# V1.91 — Armure de terre : validation stricte des choix du MJ

Un choix de dépense associé à une proposition refusée, interceptée, devenue obsolète, à un état déjà absorbé ou à une réserve épuisée n’est plus ignoré silencieusement : la validation est refusée sans modifier le combat. Les choix valides restent opérationnels.
