# V0.56 — Priorités des protections et attaques multi-cibles

- **Protection avant abri** : si une attaque est interceptée, elle ne consomme pas simultanément l’abri de l’allié. L’abri reste disponible pour une attaque ultérieure.
- **Ciblage des abris** : l’absorption est désormais indexée par attaque **et par cible** ; une attaque multi-cibles ne protège pas par erreur les personnages non couverts.
- **Régressions** : cinq scénarios ajoutés pour les interactions entre interception, abri, prévisualisation et annulation.
- **Limites** : choix narratifs et succès des attaques restent du ressort du MJ. Aucun test navigateur n’a été réalisé.
- **Catalogue** : 8/102 techniques avancées validées, inchangé ; cette livraison consolide les règles existantes.
