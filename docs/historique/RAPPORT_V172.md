# V1.72 — Étoile de lave : sources concurrentes d’Avantagé

- Une source externe d’Avantagé validée après activation est mémorisée sur l’étoile.
- Un statut Avantagé temporaire toujours actif est protégé lors de l’extinction volontaire ou automatique.
- Plusieurs étoiles actives et une armure de Terre sont prises en compte avant de retirer Avantagé.
- Les effets rejetés ne comptent pas comme source externe.
- Les statuts appliqués manuellement hors moteur peuvent encore nécessiter un arbitrage MJ.
- Régression automatisée ajoutée ; tous les anciens tests conservés.
