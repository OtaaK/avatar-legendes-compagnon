# V1.94 — Entraves de métal : coexistence des sources

La libération ne retire plus Gêné si un Bouclier de roche ou un statut de passe encore actif le fournit. Le calcul d’Avantagé évite de supprimer l’avantage lorsqu’une autre entrave active du même maître le justifie. Restauration et historique conservés.
