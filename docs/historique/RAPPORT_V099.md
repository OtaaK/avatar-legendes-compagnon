# Rapport V0.99 — Intitulés narratifs de scène

- Ajout du bouton **Nommer la scène (MJ)** dans le déroulement.
- Validation de 1 à 120 caractères ; suppression des espaces extérieurs et rejet des noms vides.
- Affichage du titre dans l’en-tête de passe ; échappement HTML pour éviter toute injection.
- Enregistrement dans l’historique et annulation ; modification identique sans nouvel historique.
- Un changement de scène efface son ancien intitulé, avec restauration possible par annulation.
- Modification interdite lorsque des propositions attendent la validation du MJ.

Le titre est une information narrative, sans effet mécanique. Les autres effets temporaires restent soumis à l’arbitrage MJ.
