# V1.78 — Étoile de lave : fatigue maximale

Le MJ peut choisir un état libre lorsque la fatigue d’entretien dépasse la jauge de 5. Le moteur vérifie la conversion, interdit les états déjà cochés, assure la transaction atomique et permet Annuler. Sans état libre, l’arbitrage de mise hors de combat reste manuel.
