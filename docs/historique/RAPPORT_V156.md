# V1.56 — Armure de terre : retrait de statut

- À l’épuisement de la réserve, Avantagé est retiré automatiquement si aucune autre source connue n’est présente.
- Un Avantagé antérieur, une autre technique approuvée ou une autre armure active empêchent son retrait.
- Annulation transactionnelle et tests du moteur.

Limite : l’attribution historique des statuts dans les anciennes sauvegardes n’est pas complète ; une source non identifiée peut nécessiter arbitrage MJ. Les attaques doivent encore être saisies via le formulaire dédié.
