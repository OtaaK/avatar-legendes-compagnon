# V0.51 — Frapper un point faible (technique universelle, p. 286)

- Automatisation conditionnelle : coût 1 fatigue ; la cible Gênée et engagée reçoit autant de fatigue que d’états déjà cochés.
- L’engagement reste une confirmation explicite du MJ, le moteur ne disposant pas de géométrie de combat fiable.
- Refus atomiques des cibles incorrectes et des prérequis manquants.
- Interface : case de confirmation de l’engagement.
- 5 scénarios de tests dédiés, plus tests de régression antérieurs.
- **5 techniques avancées testées sur 102** ; les 102 techniques sont documentées en première passe.
- Les tests Node ne constituent pas des tests d’interface dans un navigateur réel.
