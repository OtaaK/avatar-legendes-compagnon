# V0.83 — Ciblage narratif des objets par Électrochoc

- Ajout d’un champ **Objet visé** pour Électrochoc lorsque le MJ choisit « Objet ».
- L’objet n’est plus représenté artificiellement par un adversaire : la cible technique est le lanceur pour le suivi de l’événement narratif ; seul le lanceur paie la fatigue.
- Validation du nom d’objet (non vide, au plus 100 caractères), et note persistante nommant l’objet visé.
- Prévisualisation et annulation inchangées ; tests dédiés.
- Limites : l’objet reste narratif, sans points de vie ni position simulée ; les tests historiques manquants ne sont pas restaurés.
