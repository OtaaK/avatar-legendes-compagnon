# V1.59 — Bouclier de roche : réduction de coût atomique

La consommation du bouclier est maintenant sélectionnable lors de la préparation d’une technique de Terre. Le coût en fatigue est réduit de 1 dans la même validation que les effets ; le bouclier n’est retiré qu’après application réussie. Refus intégral, prévisualisation, erreurs et annulation ne doivent pas consommer le bouclier. Les techniques gratuites sont refusées pour cette option. Le bouclier doit appartenir au lanceur.

Le MJ conserve la décision narrative concernant l'emplacement fixe et la matière disponible. Les protections provenant d'autres sources de Gêné non traçables restent une limite historique.

Validation : 118/118 tests Node.js, syntaxe JavaScript.
