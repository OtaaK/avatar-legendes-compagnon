# Arbitrages préparés, aucune intégration autorisée

Les invariants confirmés par le propriétaire ne sont pas remis au vote : formats Codex
v1/v2, toutes les valeurs métier autorisées, trois maîtrises distinctes, deux principes
structurés, distinction états/statuts, conservation des relations/historiques, aucune
promotion de données fictives en règle. Les points ci-dessous complètent ces contraintes.
Ils ne bloquent pas la livraison C0, mais conditionnent les raccordements concernés.
