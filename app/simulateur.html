Tes données

Gestion

Les sauvegardes restent dans ce navigateur. Conserve un export JSON dans un dossier personnel pour pouvoir les retrouver.

Sauvegarde complète

Fiches et combat réunis dans un fichier. Une confirmation est demandée avant de remplacer les données actuelles.

Retour à la version précédente

L’activation des profils PNJ, des Lieux ou du suivi des Livrets conserve l’état local antérieur. Le bouton ci-dessous exporte le point précédant la première de ces activations. Cette copie permet de retrouver ses données avec l’ancienne application ; les changements suivants restent dans la nouvelle version.

Combattants

Une copie est ajoutée au combat. La fiche permanente n’est modifiée qu’après confirmation avec « Reporter sur la fiche ».

Le bouton « Modifier le combattant » permet de changer son nom et ses ressources avant la révélation des approches.

Journal

Version de démonstration : assiste certaines techniques de base et universelles ; les réactions complexes restent soumises au MJ. Les autres techniques et les effets narratifs exigent encore l’arbitrage du MJ. Le calcul de posture est saisi, non lancé. Les techniques non automatisées sont envoyées à l’arbitrage du MJ.
